## 解法




### 方法一：优先队列（小根堆）



> **思考**
>
> 超级丑数只含给定质因子。若从小到大枚举正整数并试除，当 $n$ 很大时线性扫描过慢。
>
> 从 $1$ 出发，每次弹出堆顶 $x$，再把 $x\times p$ 压回（防止溢出）。遇 $x$ 能被当前 $p$ 整除则停止后续质数，相当于欧拉筛去重。弹出 $n$ 次即为第 $n$ 个。



我们用一个优先队列（小根堆）维护所有可能的超级丑数，初始时将 $1$ 放入队列中。

每次从队列中取出最小的超级丑数 $x$，将 $x$ 乘以数组 `primes` 中的每个数，将乘积放入队列中，然后重复上述操作 $n$ 次即可得到第 $n$ 个超级丑数。

由于题目保证第 $n$ 个超级丑数在 $32$ 位带符号整数范围内，因此，我们将乘积放入队列之前，可以先判断乘积是否超过 $2^{31} - 1$，如果超过，则不需要将乘积放入队列中。另外，可以使用欧拉筛优化。

时间复杂度 $O(n \times m \times \log (n \times m))$，空间复杂度 $O(n \times m)$。其中 $m$ 和 $n$ 分别为数组 `primes` 的长度和给定的整数 $n$。




#### Python3


```python
class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        q = [1]
        x = 0
        mx = (1 << 31) - 1
        for _ in range(n):
            x = heappop(q)
            for k in primes:
                if x <= mx // k:
                    heappush(q, k * x)
                if x % k == 0:
                    break
        return x
```


### 方法二：动态规划 + 多指针堆



> **思考**
>
> 方法一对每个已生成丑数向所有质数扩展，堆中候选过多。改为每个质数只保留一条指针：堆顶给出当前最小候选，写入后再把该质数的下一倍数压回。候选规模降为 $O(m)$，时间 $O(n\log m)$。



用数组 $ugly[1..n]$ 存放前 $n$ 个超级丑数，并维护一个小根堆。堆中每个元素对应一个质数 $p$，记录当前应由 $p$ 乘以第 $\textit{index}$ 个超级丑数得到的候选值。

初始时 $ugly[1] = 1$，把每个质数 $p$ 以 $(p, p, 2)$ 入堆。每次取出堆顶最小值写入 $ugly$，再把该质数的指针后移并压回堆中。这样每个质数只维护一条指针，避免方法一中对已生成丑数的全局扩展。

时间复杂度 $O(n \times \log m)$，空间复杂度 $O(n + m)$。其中 $m$ 为数组 $\textit{primes}$ 的长度。
