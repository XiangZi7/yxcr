## 解法




### 方法一



> **思考**
>
> 有序质数数组中第 $k$ 小的真分数 $arr[i]/arr[j]$（ $i<j$）。 $n\le 1000$，枚举全部 $O(n^2)$ 对再排序偏慢。
>
> 固定分母 $arr[j]$ 时分子增大分数增大，全体分数构成 $n-1$ 条有序链。多路归并用小根堆每次弹出当前最小，把同一 $j$ 的下一个分子推入。
>
> 初态放入每条链的最小元 $arr[0]/arr[j]$，弹出 $k-1$ 次后堆顶即答案。






#### Python3


```python
class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        h = [(1 / y, 0, j + 1) for j, y in enumerate(arr[1:])]
        heapify(h)
        for _ in range(k - 1):
            _, i, j = heappop(h)
            if i + 1 < j:
                heappush(h, (arr[i + 1] / arr[j], i + 1, j))
        return [arr[h[0][1]], arr[h[0][2]]]
```
