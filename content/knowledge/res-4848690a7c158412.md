## 解法




### 方法一：排序 + 二分查找



> **思考**
>
> 数对距离的第 $k$ 小。 $n\le 10^4$，枚举全部 $O(n^2)$ 对再排序超出限制。距离取值在 $[0, \max-\min]$，具有单调性：不大于 $d$ 的对数随 $d$ 增大而不减。
>
> 因此可以对距离二分，判定「有多少对数对距离 $\le d$」。数组排序后，对每个右端点 $b$，左端最小合法值是 $b-d$，用二分找到下界即可在 $O(n\log n)$ 内数完。
>
> 在 $[0, nums[-1]-nums[0]]$ 上二分最小的 $d$ 使得计数 $\ge k$，即为第 $k$ 小距离。



先对 $nums$ 数组进行排序，然后在 $[0, nums[n-1]-nums[0]]$ 范围内二分枚举数对距离 $dist$，若 $nums$ 中数对距离小于等于 $dist$ 的数量 $cnt$ 大于等于 $k$，则尝试缩小 $dist$，否则尝试扩大 $dist$。

时间复杂度 $O(nlogn×logm)$，其中 $n$ 表示 $nums$ 的长度， $m$ 表示 $nums$ 中两个数的最大差值。




#### Python3


```python
class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        def count(dist):
            cnt = 0
            for i, b in enumerate(nums):
                a = b - dist
                j = bisect_left(nums, a, 0, i)
                cnt += i - j
            return cnt

        nums.sort()
        return bisect_left(range(nums[-1] - nums[0]), k, key=count)
```


#### TypeScript


```ts
function smallestDistancePair(nums: number[], k: number): number {
    nums.sort((a, b) => a - b);
    const n = nums.length;
    let left = 0,
        right = nums[n - 1] - nums[0];
    while (left < right) {
        let mid = (left + right) >> 1;
        let count = 0,
            i = 0;
        for (let j = 0; j < n; j++) {
            // 索引[i, j]距离nums[j]的距离<=mid
            while (nums[j] - nums[i] > mid) {
                i++;
            }
            count += j - i;
        }
        if (count >= k) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```
