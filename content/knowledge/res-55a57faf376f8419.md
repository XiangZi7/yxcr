## 解法




### 方法一：动态规划



> **思考**
>
> 子序列需保持原相对顺序且公差固定为 $difference$。 $n \le 10^5$，枚举子集不可行。以 $x$ 结尾的最长长度只依赖以 $x-difference$ 结尾的长度，且该前驱若存在必已在此前出现。
>
> 从左到右扫描，令 $f[x]=f[x-difference]+1$。哈希表按值索引前驱，一遍得到所有结尾处的最长长度，取最大即可。



我们可以使用哈希表 $f$ 来存储以 $x$ 结尾的最长等差子序列的长度。

遍历数组 $\textit{arr}$，对于每个元素 $x$，我们更新 $f[x]$ 为 $f[x - \textit{difference}] + 1$。

遍历结束后，我们返回 $f$ 中的最大值作为答案返回即可。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为数组 $\textit{arr}$ 的长度。




#### Python3


```python
class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        f = defaultdict(int)
        for x in arr:
            f[x] = f[x - difference] + 1
        return max(f.values())
```


#### TypeScript


```ts
function longestSubsequence(arr: number[], difference: number): number {
    const f: Map<number, number> = new Map();
    for (const x of arr) {
        f.set(x, (f.get(x - difference) ?? 0) + 1);
    }
    return Math.max(...f.values());
}
```
