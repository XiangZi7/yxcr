## 解法




### 方法一



> **思考**
>
> 求两个 $n$ 位整数乘积中最大的回文，再模 $1337$。 $n\le 8$，枚举所有乘积再判回文过大。
>
> 从大到小枚举回文的前半 $a$，镜像得到回文 $x$，再检查是否存在 $n$ 位因子 $t$（从 $10^n-1$ 向下， $t^2\ge x$）。第一个成功的 $x$ 即为最大。
>
> 先构造回文再试因子，比枚举乘积更早遇到最大值。 $n=1$ 的哨兵返回 $9$。






#### Python3


```python
class Solution:
    def largestPalindrome(self, n: int) -> int:
        mx = 10**n - 1
        for a in range(mx, mx // 10, -1):
            b = x = a
            while b:
                x = x * 10 + b % 10
                b //= 10
            t = mx
            while t * t >= x:
                if x % t == 0:
                    return x % 1337
                t -= 1
        return 9
```
