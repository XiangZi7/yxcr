## 解法




### 方法一：前缀和 + 数组或哈希表



> **思考**
>
> 恰好 $k$ 个奇数的子数组， $n \le 5\times 10^4$。奇数看成 $1$、偶数看成 $0$ 后，即前缀和之差为 $k$ 的区间个数。
>
> 扫描时维护奇数个数 $t$，用计数器查已出现的 $t-k$ 次，再登记当前 $t$。前缀和把「恰好 $k$ 个奇数」变成哈希表上的一次查询。



题目求子数组中恰好有 $k$ 个奇数的子数组个数，我们可以求出每个前缀数组中奇数的个数 $t$，记录在数组或哈希表 $cnt$ 中。对于每个前缀数组，我们只需要求出前缀数组中奇数个数为 $t-k$ 的前缀数组个数，即为以当前前缀数组结尾的子数组个数。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为数组 $nums$ 的长度。




#### Python3


```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        cnt = Counter({0: 1})
        ans = t = 0
        for v in nums:
            t += v & 1
            ans += cnt[t - k]
            cnt[t] += 1
        return ans
```


#### TypeScript


```ts
function numberOfSubarrays(nums: number[], k: number): number {
    const n = nums.length;
    const cnt = Array(n + 1).fill(0);
    cnt[0] = 1;
    let [t, ans] = [0, 0];
    for (const v of nums) {
        t += v & 1;
        ans += cnt[t - k] ?? 0;
        cnt[t] += 1;
    }
    return ans;
}
```
