## 解法




### 方法一：脑筋急转弯



> **思考**
>
> 若按秒模拟每只蚂蚁的位置，并在相遇时改向，时间可达到木板长度与蚂蚁数的乘积，在 $n\le 10^4$ 时尚可，但实现烦琐且没有必要。
>
> 两蚁相遇后各自掉头，其后续轨迹与彼此穿过、继续沿原方向前进完全相同。因此碰撞可以忽略，答案就是向左蚂蚁走到 $0$、向右蚂蚁走到 $n$ 所需时间的最大值。



题目关键点在于两只蚂蚁相遇，然后分别调转方向的情况，实际上相当于两只蚂蚁继续往原来的方向移动。因此，我们只需要求出所有蚂蚁中最远的那只蚂蚁的移动距离即可。

注意 $\textit{left}$ 和 $\textit{right}$ 数组的长度可能为 $0$。

时间复杂度 $O(n)$，其中 $n$ 为木板的长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        ans = 0
        for x in left:
            ans = max(ans, x)
        for x in right:
            ans = max(ans, n - x)
        return ans
```


#### TypeScript


```ts
function getLastMoment(n: number, left: number[], right: number[]): number {
    let ans = 0;
    for (const x of left) {
        ans = Math.max(ans, x);
    }
    for (const x of right) {
        ans = Math.max(ans, n - x);
    }
    return ans;
}
```
