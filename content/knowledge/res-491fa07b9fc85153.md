## 解法




### 方法一



> **思考**
>
> 视野是以自身为顶点、张角为 $\textit{angle}$ 的扇形，点数可达 $10^5$，枚举每一对极角边界会超时。与位置重合的点对任意朝向均可见，应单独计入。
>
> 将其余点换成相对极角并排序后，可见集合对应长度为 $\textit{angle}$ 的圆周窗口。将序列拼接一份加上 $2\pi$，即可把环形窗口化为线性区间。
>
> 对每个左端点 $v[i]$，用二分查找不超过 $v[i]+\theta$ 的最右位置，窗口点数取最大后再加上重合点数。






#### Python3


```python
class Solution:
    def visiblePoints(
        self, points: List[List[int]], angle: int, location: List[int]
    ) -> int:
        v = []
        x, y = location
        same = 0
        for xi, yi in points:
            if xi == x and yi == y:
                same += 1
            else:
                v.append(atan2(yi - y, xi - x))
        v.sort()
        n = len(v)
        v += [deg + 2 * pi for deg in v]
        t = angle * pi / 180
        mx = max((bisect_right(v, v[i] + t) - i for i in range(n)), default=0)
        return mx + same
```
