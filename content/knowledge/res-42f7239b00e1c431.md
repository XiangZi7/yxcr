## 解法




### 方法一



> **思考**
>
> 每个值落在 $[1,n]$ 且至多出现两次，进阶要求线性时间、常数额外空间。哈希表能找重复，但多用 $O(n)$ 空间。
>
> 把 $v$ 交换到下标 $v-1$（循环排序）。结束后位置 $i$ 上若不是 $i+1$，则该值是多出来的重复。
>
> 交换持续到 $nums[i]=nums[nums[i]-1]$，重复值会与已就位的那个撞车而停下，不会死循环。






#### Python3


```python
class Solution:
    def findDuplicates(self, nums: List[int]) -> List[int]:
        for i in range(len(nums)):
            while nums[i] != nums[nums[i] - 1]:
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
        return [v for i, v in enumerate(nums) if v != i + 1]
```


#### TypeScript


```ts
function findDuplicates(nums: number[]): number[] {
    for (let i = 0; i < nums.length; i++) {
        while (nums[i] !== nums[nums[i] - 1]) {
            const temp = nums[i];
            nums[i] = nums[temp - 1];
            nums[temp - 1] = temp;
        }
    }
    const ans: number[] = [];
    for (let i = 0; i < nums.length; i++) {
        if (nums[i] !== i + 1) {
            ans.push(nums[i]);
        }
    }
    return ans;
}
```
