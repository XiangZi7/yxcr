## 解法




### 方法一：动态规划



> **思考**
>
> 排列（顺序不同算不同）凑出 $target$ 的方案数。若按组合背包外层物品，会漏掉不同顺序。须先枚举和、再枚举末项。
>
> $f[i]$ 为和为 $i$ 的排列数， $f[0]=1$。对每个 $i$ 枚举 $x$，若 $i\ge x$ 则加上 $f[i-x]$。与 322 同形，目标从最少枚数改为计数。



我们定义 $f[i]$ 表示总和为 $i$ 的元素组合的个数，初始时 $f[0] = 1$，其余 $f[i] = 0$。最终答案即为 $f[target]$。

对于 $f[i]$，我们可以枚举数组中的每个元素 $x$，如果 $i \ge x$，则 $f[i] = f[i] + f[i - x]$。

最后返回 $f[target]$ 即可。

时间复杂度 $O(n \times target)$，空间复杂度 $O(target)$。其中 $n$ 为数组的长度。




#### Python3


```python
class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        f = [1] + [0] * target
        for i in range(1, target + 1):
            for x in nums:
                if i >= x:
                    f[i] += f[i - x]
        return f[target]
```


#### TypeScript


```ts
function combinationSum4(nums: number[], target: number): number {
    const f: number[] = Array(target + 1).fill(0);
    f[0] = 1;
    for (let i = 1; i <= target; ++i) {
        for (const x of nums) {
            if (i >= x) {
                f[i] += f[i - x];
            }
        }
    }
    return f[target];
}
```
