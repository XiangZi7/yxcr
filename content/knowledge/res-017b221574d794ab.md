## 解法




### 方法一：优先队列（小根堆）



> **思考**
>
> 数据流中持续插入，并随时询问第 $k$ 大。若每次排序或扫描全部历史， $n$ 与询问次数均可到 $10^4$，总代价偏高。
>
> 第 $k$ 大只取决于当前最大的 $k$ 个数，更小的元素永远不会成为答案，不必长期保存。维护大小为 $k$ 的集合时，堆顶恰好是其中的最小值，也就是全体中的第 $k$ 大。
>
> 因此用小根堆保存这 $k$ 个数：新元素入堆，超过 $k$ 个则弹出堆顶。初始化把 $\textit{nums}$ 依次加入即可，单次 $\textit{add}$ 为 $O(\log k)$。



我们维护一个优先队列（小根堆） $\textit{minQ}$。

初始化时，我们将数组 $\textit{nums}$ 中的元素依次加入 $\textit{minQ}$，并保持 $\textit{minQ}$ 的大小不超过 $k$。时间复杂度 $O(n \times \log k)$。

每次加入一个新元素时，如果 $\textit{minQ}$ 的大小超过了 $k$，我们就将堆顶元素弹出，保证 $\textit{minQ}$ 的大小为 $k$。时间复杂度 $O(\log k)$。

这样， $\textit{minQ}$ 中的元素就是数组 $\textit{nums}$ 中最大的 $k$ 个元素，堆顶元素就是第 $k$ 大的元素。

空间复杂度 $O(k)$。




#### Python3


```python
class KthLargest:

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.min_q = []
        for x in nums:
            self.add(x)

    def add(self, val: int) -> int:
        heappush(self.min_q, val)
        if len(self.min_q) > self.k:
            heappop(self.min_q)
        return self.min_q[0]

```


#### TypeScript


```ts
class KthLargest {
    #k: number = 0;
    #minQ = new MinPriorityQueue<number>();

    constructor(k: number, nums: number[]) {
        this.#k = k;
        for (const x of nums) {
            this.add(x);
        }
    }

    add(val: number): number {
        this.#minQ.enqueue(val);
        if (this.#minQ.size() > this.#k) {
            this.#minQ.dequeue();
        }
        return this.#minQ.front();
    }
}
```
