## 解法




### 方法一：栈



> **思考**
>
> 反复扫描删除连续 $k$ 个相同字符， $n \le 10^5$ 时最坏会多次重扫。删除具有局部性：只有相邻的相同字符会合并，且删除后两侧可能再相遇。
>
> 栈按从左到右的顺序保存尚未消除的字符及其连续次数。当前字符与栈顶相同则累加；次数达到 $k$ 则整段弹出，相当于一次消除。
>
> 为此栈中存 $(字符, 次数)$，入栈时对 $k$ 取模以便刚好满 $k$ 时弹出。一遍扫描后栈内剩余即最终串。



我们可以遍历字符串 $s$，维护一个栈，栈中存储的是字符和该字符出现的次数。当遍历到字符 $c$ 时，如果栈顶元素的字符和 $c$ 相同，则将栈顶元素的次数加一，否则将字符 $c$ 和次数 $1$ 入栈。当栈顶元素的次数等于 $k$ 时，将栈顶元素出栈。

遍历完字符串 $s$ 后，栈中存储的就是最终结果。我们可以将栈中的元素依次弹出，拼接成字符串即可。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为字符串 $s$ 的长度。




#### Python3


```python
class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        stk = []
        for c in s:
            if stk and stk[-1][0] == c:
                stk[-1][1] = (stk[-1][1] + 1) % k
                if stk[-1][1] == 0:
                    stk.pop()
            else:
                stk.append([c, 1])
        ans = [c * v for c, v in stk]
        return "".join(ans)
```
