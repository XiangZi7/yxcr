## 解法




### 方法一：位运算



> **思考**
>
> 写成二进制再按位取反可以得到补数，但 $n$ 可达 $10^9$，且补数不含前导零对应的高位翻转， $n=0$ 还需单独得到 $1$。
>
> 从低到高逐位处理时，只需对 $n$ 中实际出现过的位取反并写入答案，处理完后 $n$ 右移为空即停，自然不会碰到更高的零位。
>
> 用 $i$ 记录当前位数，将 $(n\bmod 2)$ 取反后或入 $\textit{ans}$ 的第 $i$ 位，直到 $n$ 变为 $0$。



我们首先判断 $n$ 是否为 $0$，如果是，则返回 $1$。

接着我们定义两个变量 $\textit{ans}$ 和 $i$，初始化为 $0$。然后我们遍历 $n$，在每次遍历中，我们将 $\textit{ans}$ 的第 $i$ 位设置为 $n$ 的第 $i$ 位取反，然后将 $i$ 加 $1$，并且 $n$ 右移 $1$ 位。

最后返回 $\textit{ans}$ 即可。

时间复杂度 $O(\log n)$，其中 $n$ 为给定的十进制数。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        if n == 0:
            return 1
        ans = i = 0
        while n:
            ans |= ((n & 1 ^ 1) << i)
            i += 1
            n >>= 1
        return ans
```


#### TypeScript


```ts
function bitwiseComplement(n: number): number {
    if (n === 0) {
        return 1;
    }
    let ans = 0;
    for (let i = 0; n; n >>= 1) {
        ans |= ((n & 1) ^ 1) << i++;
    }
    return ans;
}
```
