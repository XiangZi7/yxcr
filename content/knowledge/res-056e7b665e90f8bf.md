## 解法




### 方法一：贪心 + 二分查找



> **思考**
>
> 套娃信封须宽高都严格更大，求最多层数。二维 LIS 若 $O(n^2)$， $n$ 达 $10^5$ 不可行。宽递增后，高上的 LIS 即答案；同宽须避免套自己。
>
> 按宽升序、同宽按高降序排序，再对高做贪心 LIS：大于末尾则追加，否则二分替换。同宽的高降序保证至多选一个。



时间复杂度 O(nlogn)。




#### Python3


```python
class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        envelopes.sort(key=lambda x: (x[0], -x[1]))
        d = [envelopes[0][1]]
        for _, h in envelopes[1:]:
            if h > d[-1]:
                d.append(h)
            else:
                idx = bisect_left(d, h)
                d[idx] = h
        return len(d)
```
