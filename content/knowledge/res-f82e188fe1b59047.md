## 解法




### 方法一：位运算



> **思考**
>
> 汉明距离是二进制不同位的个数。逐位比较需要循环 $32$ 次。
>
> $x\oplus y$ 的 $1$ 位恰是不同位，对其做 $\textit{bit\_count}$ 即可。
>
> 异或把比较收成一次字运算，再数 $1$ 的硬件指令或循环均可。



我们将 $x$ 和 $y$ 按位异或，得到的结果中的 $1$ 的个数就是汉明距离。

时间复杂度 $O(1)$，空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        return (x ^ y).bit_count()
```


#### TypeScript


```ts
function hammingDistance(x: number, y: number): number {
    x ^= y;
    let ans = 0;
    while (x) {
        x -= x & -x;
        ++ans;
    }
    return ans;
}
```
