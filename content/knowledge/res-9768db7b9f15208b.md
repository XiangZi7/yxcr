## 解法




### 方法一：逆序遍历



> **思考**
>
> 每位要换成右侧最大值，末位为 $-1$。从左再扫右侧会重复工作。自右向左维护后缀最大值 $mx$，先把当前位置写成旧的 $mx$，再用当前原值更新 $mx$。一遍逆序， $O(1)$ 额外空间。



我们用一个变量 $mx$ 记录当前位置右侧的最大值，初始时 $mx = -1$。

然后我们从右向左遍历数组，对于每个位置 $i$，我们记当前位置的值为 $x$，将当前位置的值更新为 $mx$，然后更新 $mx = \max(mx, x)$。

最后返回原数组即可。

时间复杂度 $O(n)$，其中 $n$ 为数组长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        mx = -1
        for i in reversed(range(len(arr))):
            x = arr[i]
            arr[i] = mx
            mx = max(mx, x)
        return arr
```


#### TypeScript


```ts
function replaceElements(arr: number[]): number[] {
    for (let i = arr.length - 1, mx = -1; ~i; --i) {
        const x = arr[i];
        arr[i] = mx;
        mx = Math.max(mx, x);
    }
    return arr;
}
```
