## 解法




### 方法一：栈模拟



> **思考**
>
> 整理好的串不含相邻的大小写同一字母。反复从左扫描删除在 $n\le 100$ 时可行，但一次删除可能让更早的一对撞上，需要来回走。
>
> 栈保存当前已整理前缀：新字符若与栈顶相差 $32$（恰为一对大小写），则弹出栈顶，相当于删掉这一对；否则入栈。线性扫完即得结果。



时间复杂度 $O(n)$，空间复杂度 $O(n)$，其中 $n$ 是字符串 `s` 的长度。




#### Python3


```python
class Solution:
    def makeGood(self, s: str) -> str:
        stk = []
        for c in s:
            if not stk or abs(ord(stk[-1]) - ord(c)) != 32:
                stk.append(c)
            else:
                stk.pop()
        return "".join(stk)
```
