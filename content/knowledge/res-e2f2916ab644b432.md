## 解法




### 方法一



> **思考**
>
> $\textit{people}[i]=[h,k]$ 表示前面恰有 $k$ 个身高不小于 $h$ 的人。若先排矮的，后插入的高的人会改变已在队列中的人的 $k$。
>
> 按身高降序、 $k$ 升序插入：队列里已有的人都更高或等高，把新人插到下标 $k$，恰好满足「前面有 $k$ 个更高或等身高的人」，且不会破坏已放置者的相对计数。
>
> 高的人先就位，矮的人插入时对更高者不可见，这是操作顺序成立的原因。






#### Python3


```python
class Solution:
    def reconstructQueue(self, people: List[List[int]]) -> List[List[int]]:
        people.sort(key=lambda x: (-x[0], x[1]))
        ans = []
        for p in people:
            ans.insert(p[1], p)
        return ans
```
