## 解法




### 方法一：模拟



> **思考**
>
> $n\le 10^5$，记录上一个 $1$ 的下标 $j$，遇到新的 $1$ 时检查中间 $0$ 的个数 $i-j-1$ 是否小于 $k$。一遍扫描即可。



我们可以遍历数组 $\textit{nums}$，用变量 $j$ 记录上一个 $1$ 的下标，那么当前位置 $i$ 的元素为 $1$ 时，只需要判断 $i - j - 1$ 是否小于 $k$ 即可。如果小于 $k$，则说明存在两个 $1$ 之间的 $0$ 的个数小于 $k$，返回 $\text{false}$；否则，将 $j$ 更新为 $i$，继续遍历数组。

遍历结束后，返回 $\text{true}$。

时间复杂度 $O(n)$，其中 $n$ 为数组 $\textit{nums}$ 的长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        j = -inf
        for i, x in enumerate(nums):
            if x:
                if i - j - 1 < k:
                    return False
                j = i
        return True
```


#### TypeScript


```ts
function kLengthApart(nums: number[], k: number): boolean {
    let j = -(k + 1);
    for (let i = 0; i < nums.length; ++i) {
        if (nums[i] === 1) {
            if (i - j - 1 < k) {
                return false;
            }
            j = i;
        }
    }
    return true;
}
```
