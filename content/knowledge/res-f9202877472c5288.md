## 解法




### 方法一：一次遍历



> **思考**
>
> 判断数组是否单调不降或不升。 $n\le 10^5$，一次遍历同时检查两种方向即可。
>
> 相邻两两比较，分别验证是否全 $\le$ 或全 $\ge$，满足其一即为单调。



遍历数组，如果出现递增或递减的情况，记录下来。判断是否出现过递增和递减的情况，如果都出现过，说明不是单调数组，返回 `false`。

否则遍历结束，说明是单调数组，返回 `true`。

时间复杂度 $O(n)$，其中 $n$ 为数组长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def isMonotonic(self, nums: List[int]) -> bool:
        asc = all(a <= b for a, b in pairwise(nums))
        desc = all(a >= b for a, b in pairwise(nums))
        return asc or desc
```


#### TypeScript


```ts
function isMonotonic(nums: number[]): boolean {
    let [asc, desc] = [false, false];
    for (let i = 1; i < nums.length; ++i) {
        if (nums[i - 1] < nums[i]) {
            asc = true;
        } else if (nums[i - 1] > nums[i]) {
            desc = true;
        }
        if (asc && desc) {
            return false;
        }
    }
    return true;
}
```
