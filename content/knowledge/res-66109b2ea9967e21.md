## 解法




### 方法一：动态规划



> **思考**
>
> 机器人每步只能向右或向下。若从起点直接搜索全部路径，格点规模 $m, n \le 100$，路径条数可达组合数级别，同一格子会被反复走到，时间无法接受。
>
> 注意到到达 $(i, j)$ 的路径只可能来自上方或左方，且两类来源互不重叠。因此可以用 $f[i][j]$ 记录走到该格的方案数，按行列顺序填表，保证转移所依赖的状态已经计算完毕。



我们定义 $f[i][j]$ 表示从左上角走到 $(i, j)$ 的路径数量，初始时 $f[0][0] = 1$，答案为 $f[m - 1][n - 1]$。

考虑 $f[i][j]$：

- 如果 $i \gt 0$，那么 $f[i][j]$ 可以从 $f[i - 1][j]$ 走一步到达，因此 $f[i][j] = f[i][j] + f[i - 1][j]$；
- 如果 $j \gt 0$，那么 $f[i][j]$ 可以从 $f[i][j - 1]$ 走一步到达，因此 $f[i][j] = f[i][j] + f[i][j - 1]$。

因此，我们有如下的状态转移方程：

$$
f[i][j] = \begin{cases}
1 & i = 0, j = 0 \\
f[i - 1][j] + f[i][j - 1] & \textit{otherwise}
\end{cases}
$$

最终的答案即为 $f[m - 1][n - 1]$。

时间复杂度 $O(m \times n)$，空间复杂度 $O(m \times n)$。其中 $m$ 和 $n$ 分别是网格的行数和列数。




#### Python3


```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        f = [[0] * n for _ in range(m)]
        f[0][0] = 1
        for i in range(m):
            for j in range(n):
                if i:
                    f[i][j] += f[i - 1][j]
                if j:
                    f[i][j] += f[i][j - 1]
        return f[-1][-1]
```


#### TypeScript


```ts
function uniquePaths(m: number, n: number): number {
    const f: number[][] = Array(m)
        .fill(0)
        .map(() => Array(n).fill(0));
    f[0][0] = 1;
    for (let i = 0; i < m; ++i) {
        for (let j = 0; j < n; ++j) {
            if (i > 0) {
                f[i][j] += f[i - 1][j];
            }
            if (j > 0) {
                f[i][j] += f[i][j - 1];
            }
        }
    }
    return f[m - 1][n - 1];
}
```


### 方法二：动态规划（预处理边界）



> **思考**
>
> 方法一对每个格子都要判断上方、左方是否存在，边界处反复走分支。第一行只能从左侧到达、第一列只能从上方到达，这些格子的路径数均为 $1$。预先填好边界后，内部格子即可直接相加，实现更为简洁，渐近复杂度不变。



先把第一行、第一列全部置为 $1$，再只填内部格子 $f[i][j] = f[i-1][j] + f[i][j-1]$。时间和空间复杂度仍为 $O(m \times n)$。




#### Python3


```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        f = [[1] * n for _ in range(m)]
        for i in range(1, m):
            for j in range(1, n):
                f[i][j] = f[i - 1][j] + f[i][j - 1]
        return f[-1][-1]
```


#### TypeScript


```ts
function uniquePaths(m: number, n: number): number {
    const f: number[][] = Array(m)
        .fill(0)
        .map(() => Array(n).fill(1));
    for (let i = 1; i < m; ++i) {
        for (let j = 1; j < n; ++j) {
            f[i][j] = f[i - 1][j] + f[i][j - 1];
        }
    }
    return f[m - 1][n - 1];
}
```


### 方法三：动态规划（滚动数组）



> **思考**
>
> 前两种方法均需维护整张 $m \times n$ 表。然而 $f[i][j]$ 只依赖上一行的 $f[i-1][j]$ 以及同行左侧的 $f[i][j-1]$，行这一维可以压缩。将状态压成长度为 $n$ 的一维数组后， $f[j]$ 在更新前仍保存上一行的值，与 $f[j-1]$ 相加即得到当前行。空间降至 $O(n)$，时间不变。



$f[i][j]$ 只与上一行和左边有关，去掉第一维后用长度为 $n$ 的一维数组滚动即可。时间复杂度 $O(m \times n)$，空间复杂度 $O(n)$。




#### Python3


```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        f = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                f[j] += f[j - 1]
        return f[-1]
```


#### TypeScript


```ts
function uniquePaths(m: number, n: number): number {
    const f: number[] = Array(n).fill(1);
    for (let i = 1; i < m; ++i) {
        for (let j = 1; j < n; ++j) {
            f[j] += f[j - 1];
        }
    }
    return f[n - 1];
}
```
