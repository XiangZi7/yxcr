## 解法




### 方法一：哈希表



> **思考**
>
> 是否存在 $i \neq j$ 使 $arr[i]=2\,arr[j]$。双重循环在 $n \le 500$ 可过，但一遍哈希即可：扫描时若 $2x$ 或（偶数时） $x/2$ 已出现则成功，否则把 $x$ 放入集合。集合只含左侧元素，自然保证下标不同。



我们定义一个哈希表 $s$，用于记录访问过的元素。

遍历数组 $arr$，对于每个元素 $x$，如果 $x$ 的两倍或者 $x$ 的一半在哈希表 $s$ 中，那么返回 `true`。否则将 $x$ 加入哈希表 $s$。

若遍历结束后没有找到满足条件的元素，返回 `false`。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为数组 $arr$ 的长度。




#### Python3


```python
class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        s = set()
        for x in arr:
            if x * 2 in s or (x % 2 == 0 and x // 2 in s):
                return True
            s.add(x)
        return False
```


#### TypeScript


```ts
function checkIfExist(arr: number[]): boolean {
    const s: Set<number> = new Set();
    for (const x of arr) {
        if (s.has(x * 2) || (x % 2 === 0 && s.has((x / 2) | 0))) {
            return true;
        }
        s.add(x);
    }
    return false;
}
```
