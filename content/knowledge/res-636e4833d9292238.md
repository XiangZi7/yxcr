## 解法




### 方法一：计数



> **思考**
>
> 把 $s$ 变成 $t$，第 $i$ 次操作只能把某个字符沿字母表循环前进 $i$ 位，且每个 $i$ 至多用一次。 $n\le 10^5$、 $k\le 10^9$，不能模拟每一次操作。
>
> 长度不同则无解。每位的最小移位 $x\in[1,25]$ 确定，相同 $x$ 必须错开使用 $x,x+26,x+52,\ldots$。第 $cnt[x]$ 个同类需要 $x+26(cnt[x]-1)$ 步，只要该值不超过 $k$ 即可。移位 $0$ 无需操作。



我们首先判断字符串 $s$ 和字符串 $t$ 的长度是否相等，如果不相等，直接返回 `false`。

如果相等，我们可以统计每个位置的字符需要操作的最小次数，即 $cnt[x]$ 表示最小操作次数为 $x$ 的字符的个数。

如果有 $cnt[x]$ 个字符需要操作 $x$ 次，那么我们需要 $x + 26 \times (cnt[x] - 1)$ 次操作才能将这些字符转换为 $t$ 中对应的字符。因此，我们在 $[1,..25] 范围内枚举 $x$，如果 $x + 26 \times (cnt[x] - 1) \gt k$，说明我们无法将所有字符转换为 $t$ 中对应的字符，返回 `false`。

否则，枚举结束后，说明我们可以将所有字符转换为 $t$ 中对应的字符，返回 `true`。

时间复杂度 $O(n + C)$，空间复杂度 $O(C)$，其中 $n$ 为字符串 $s$ 和 $t$ 的长度；而 $C$ 为字符集大小，本题中 $C = 26$。




#### Python3


```python
class Solution:
    def canConvertString(self, s: str, t: str, k: int) -> bool:
        if len(s) != len(t):
            return False
        cnt = [0] * 26
        for a, b in zip(s, t):
            x = (ord(b) - ord(a) + 26) % 26
            cnt[x] += 1
        for i in range(1, 26):
            if i + 26 * (cnt[i] - 1) > k:
                return False
        return True
```
