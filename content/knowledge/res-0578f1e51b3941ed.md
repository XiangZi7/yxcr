## 解法




### 方法一



> **思考**
>
> 长度为 $2n-1$ 的序列中， $1$ 出现一次， $2..n$ 各出现两次且间距恰为该数。 $n$ 较小，可回溯搜索。
>
> 字典序最大要求优先放置较大的数。从左到右填空位，对每个空位从 $n$ 试到 $2$，再试 $1$。
>
> $\textit{path}$ 记录已填值， $\textit{cnt}$ 记录剩余次数。数 $i$ 占用 $u$ 与 $u+i$；一旦填满 $2n-1$ 个位置即得到题目保证存在的解。






#### Python3


```python
class Solution:
    def constructDistancedSequence(self, n: int) -> List[int]:
        def dfs(u):
            if u == n * 2:
                return True
            if path[u]:
                return dfs(u + 1)
            for i in range(n, 1, -1):
                if cnt[i] and u + i < n * 2 and path[u + i] == 0:
                    cnt[i] = 0
                    path[u] = path[u + i] = i
                    if dfs(u + 1):
                        return True
                    path[u] = path[u + i] = 0
                    cnt[i] = 2
            if cnt[1]:
                cnt[1], path[u] = 0, 1
                if dfs(u + 1):
                    return True
                path[u], cnt[1] = 0, 1
            return False

        path = [0] * (n * 2)
        cnt = [2] * (n * 2)
        cnt[1] = 1
        dfs(1)
        return path[1:]
```
