## 解法




### 方法一



> **思考**
>
> 逐步和必须始终至少为 $1$。设起始值为 $x$，则所有前缀和加上 $x$ 都不小于 $1$，即 $x\ge 1-\min\textit{prefix}$。 $x$ 本身还至少为 $1$。
>
> $n\le 100$，一遍扫描即可同时得到前缀和与其最小值 $t$，答案为 $\max(1,1-t)$。






#### Python3


```python
class Solution:
    def minStartValue(self, nums: List[int]) -> int:
        s, t = 0, inf
        for num in nums:
            s += num
            t = min(t, s)
        return max(1, 1 - t)
```


#### TypeScript


```ts
function minStartValue(nums: number[]): number {
    let sum = 0;
    let min = Infinity;
    for (const num of nums) {
        sum += num;
        min = Math.min(min, sum);
    }
    return Math.max(1, 1 - min);
}
```


### 方法二



> **思考**
>
> 方法一在扫描中维护最小值。先用 `accumulate` 得到全部前缀，再取 $\min$，判定公式相同，只是把前缀数组显式化。






#### Python3


```python
class Solution:
    def minStartValue(self, nums: List[int]) -> int:
        s = list(accumulate(nums))
        return 1 if min(s) >= 0 else abs(min(s)) + 1
```
