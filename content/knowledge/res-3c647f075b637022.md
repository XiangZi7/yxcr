## 解法




### 方法一



> **思考**
>
> 数对给出祖先关系：边出现当且仅当一方是另一方的祖先。需要判断这样的有根树有 $0$、 $1$ 还是多于 $1$ 棵。
>
> 度数（邻接对数）越大的点越靠近根。将点按度数升序排列后，每个点的父候选是度数不更小且与之相邻的点。
>
> 检验该候选是否覆盖当前点的全部邻接；多个点无法找到父则不能成树。若存在度数相同的父子，则方案多于一；否则恰好一棵。






#### Python3


```python
class Solution:
    def checkWays(self, pairs: List[List[int]]) -> int:
        g = [[False] * 510 for _ in range(510)]
        v = defaultdict(list)
        for x, y in pairs:
            g[x][y] = g[y][x] = True
            v[x].append(y)
            v[y].append(x)
        nodes = []
        for i in range(510):
            if v[i]:
                nodes.append(i)
                g[i][i] = True
        nodes.sort(key=lambda x: len(v[x]))
        equal = False
        root = 0
        for i, x in enumerate(nodes):
            j = i + 1
            while j < len(nodes) and not g[x][nodes[j]]:
                j += 1
            if j < len(nodes):
                y = nodes[j]
                if len(v[x]) == len(v[y]):
                    equal = True
                for z in v[x]:
                    if not g[y][z]:
                        return 0
            else:
                root += 1
        if root > 1:
            return 0
        return 2 if equal else 1
```
