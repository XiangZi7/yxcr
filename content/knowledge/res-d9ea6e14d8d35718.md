## 解法




### 方法一：贪心 + 排序



> **思考**
>
> 三人每次各取一堆，Alice 拿当前最大、我们拿次大、Bob 拿最小，求我们的总和。 $n$ 达 $10^5$，不能按轮模拟比较。
>
> 排序后 Bob 固定拿走最小的三分之一。剩余堆从左到右交替给 Alice 和我们，我们拿到的是从下标 $n/3$ 起每隔一个的那些。对其求和即可。



为了让我们获得的硬币数量最多，我们可以贪心地让 Bob 拿走最少的 $n$ 堆硬币。我们每次先让 Alice 拿走最多的一堆硬币，然后让我们拿走第二多的一堆硬币，依次循环，直到没有硬币可拿。

时间复杂度 $O(n \times \log n)$，空间复杂度 $O(\log n)$。其中 $n$ 是硬币堆数。




#### Python3


```python
class Solution:
    def maxCoins(self, piles: List[int]) -> int:
        piles.sort()
        return sum(piles[len(piles) // 3 :][::2])
```


#### TypeScript


```ts
function maxCoins(piles: number[]): number {
    piles.sort((a, b) => a - b);
    let ans = 0;
    for (let i = piles.length / 3; i < piles.length; i += 2) {
        ans += piles[i];
    }
    return ans;
}
```
