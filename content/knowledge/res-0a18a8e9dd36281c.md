## 解法




### 方法一



> **思考**
>
> $F(k)=\sum i\cdot \textit{nums}[(i+k)\bmod n]$，求最大 $F$。每次旋转后重算为 $O(n^2)$。相邻 $F$ 有线性关系。
>
> $F(k+1)=F(k)+\sum nums-n\cdot nums[n-1-k]$。先算 $F(0)$，再滚 $n-1$ 次取最大。






#### Python3


```python
class Solution:
    def maxRotateFunction(self, nums: List[int]) -> int:
        f = sum(i * v for i, v in enumerate(nums))
        n, s = len(nums), sum(nums)
        ans = f
        for i in range(1, n):
            f = f + s - n * nums[n - i]
            ans = max(ans, f)
        return ans
```


#### TypeScript


```ts
function maxRotateFunction(nums: number[]): number {
    const n = nums.length;
    const sum = nums.reduce((r, v) => r + v);
    let res = nums.reduce((r, v, i) => r + v * i, 0);
    let pre = res;
    for (let i = 1; i < n; i++) {
        pre = pre - (sum - nums[i - 1]) + nums[i - 1] * (n - 1);
        res = Math.max(res, pre);
    }
    return res;
}
```
