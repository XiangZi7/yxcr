## 解法




### 方法一：BFS



> **思考**
>
> 有向无环图上枚举 $0$ 到 $n-1$ 的全部路径。 $n\le 15$，路径数可到指数级，但必须全部输出，广搜或深搜都可以。
>
> 队列保存整条路径，弹出后若终点则收入答案，否则把每个后继接在后面再入队。



从结点 $0$ 出发，用队列保存路径，到达 $n-1$ 时记入答案。




#### Python3


```python
class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        n = len(graph)
        q = deque([[0]])
        ans = []
        while q:
            path = q.popleft()
            u = path[-1]
            if u == n - 1:
                ans.append(path)
                continue
            for v in graph[u]:
                q.append(path + [v])
        return ans
```


#### TypeScript


```ts
function allPathsSourceTarget(graph: number[][]): number[][] {
    const ans: number[][] = [];

    const dfs = (path: number[]) => {
        const curr = path.at(-1)!;
        if (curr === graph.length - 1) {
            ans.push([...path]);
            return;
        }

        for (const v of graph[curr]) {
            path.push(v);
            dfs(path);
            path.pop();
        }
    };

    dfs([0]);

    return ans;
}
```








### 方法二：DFS



> **思考**
>
> 广搜要复制整条路径。深搜在同一数组上追加、到达终点时拷贝、再弹出回溯，少一些中间分配。



从结点 $0$ 出发深度优先搜索，到达终点后回溯继续枚举。




#### Python3


```python
class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        def dfs(t):
            if t[-1] == len(graph) - 1:
                ans.append(t[:])
                return
            for v in graph[t[-1]]:
                t.append(v)
                dfs(t)
                t.pop()

        ans = []
        dfs([0])
        return ans
```
