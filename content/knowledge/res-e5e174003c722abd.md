## 解法




### 方法一：栈模拟



> **思考**
>
> 标签要正确嵌套，CDATA 原样跳过，且整段必须是一个闭合的标签树。正则难以处理嵌套与 CDATA。
>
> 用栈存尚未闭合的标签名。遇到 `<![CDATA[` 找到配对 `]]>` 并跳过；遇到结束标签则必须与栈顶相同；开始标签名需为 $1$ 到 $9$ 个大写字母。栈一旦在中途空掉说明有额外文本。结束时栈应为空。






#### Python3


```python
class Solution:
    def isValid(self, code: str) -> bool:
        def check(tag):
            return 1 <= len(tag) <= 9 and all(c.isupper() for c in tag)

        stk = []
        i, n = 0, len(code)
        while i < n:
            if i and not stk:
                return False
            if code[i : i + 9] == '<![CDATA[':
                i = code.find(']]>', i + 9)
                if i < 0:
                    return False
                i += 2
            elif code[i : i + 2] == '</':
                j = i + 2
                i = code.find('>', j)
                if i < 0:
                    return False
                t = code[j:i]
                if not check(t) or not stk or stk.pop() != t:
                    return False
            elif code[i] == '<':
                j = i + 1
                i = code.find('>', j)
                if i < 0:
                    return False
                t = code[j:i]
                if not check(t):
                    return False
                stk.append(t)
            i += 1
        return not stk
```
