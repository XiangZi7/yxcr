## 解法




### 方法一：二分查找



> **思考**
>
> 判断 $num$ 是否完全平方。从 $1$ 扫到 $\sqrt{num}$ 为 $O(\sqrt n)$。在值域上对 $x^2$ 二分即可。
>
> 在 $[1,num]$ 中找最小的 $x$ 使 $x^2\ge num$，再检查是否相等。代码用 `bisect_left` 配 $x\mapsto x^2$。



我们可以使用二分查找来解决这个问题。定义二分查找的左边界 $l = 1$，右边界 $r = num$，然后在 $[l, r]$ 的范围内查找满足 $x^2 \geq num$ 的最小整数 $x$。最后，如果 $x^2 = num$，则说明 $num$ 是一个完全平方数。

时间复杂度 $O(\log n)$，其中 $n$ 是给定的数字。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def isPerfectSquare(self, num: int) -> bool:
        l = bisect_left(range(1, num + 1), num, key=lambda x: x * x) + 1
        return l * l == num
```


#### TypeScript


```ts
function isPerfectSquare(num: number): boolean {
    let [l, r] = [1, num];
    while (l < r) {
        const mid = (l + r) >> 1;
        if (mid >= num / mid) {
            r = mid;
        } else {
            l = mid + 1;
        }
    }
    return l * l === num;
}
```


### 方法二：数学



> **思考**
>
> 二分依赖有序平方。奇数和 $1+3+\cdots+(2n-1)=n^2$，故反复减递增奇数，减到 $0$ 则为平方。实现更短，时间为 $O(\sqrt n)$。



由于 $1 + 3 + 5 + \cdots + (2n - 1) = n^2$，我们可以将 $num$ 逐渐减去 $1, 3, 5, \cdots$，如果最后 $num = 0$，则说明 $num$ 是一个完全平方数。

时间复杂度 $O(\sqrt n)$，空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def isPerfectSquare(self, num: int) -> bool:
        i = 1
        while num > 0:
            num -= i
            i += 2
        return num == 0
```


#### TypeScript


```ts
function isPerfectSquare(num: number): boolean {
    let i = 1;
    while (num > 0) {
        num -= i;
        i += 2;
    }
    return num === 0;
}
```
