## 解法




### 方法一



> **思考**
>
> 英文数字的字母互相重叠，不能按单词顺序贪心匹配。若干字母却只属于一个数字。
>
> $\texttt{z}$ 只在 zero， $\texttt{w}$ 只在 two， $\texttt{u}$ 只在 four， $\texttt{x}$ 只在 six， $\texttt{g}$ 只在 eight。扣掉这些之后， $\texttt{h}$、 $\texttt{f}$、 $\texttt{s}$ 分别确定 three、five、seven，最后用 $\texttt{o}$、 $\textit{i}$ 确定 one、nine。
>
> 按「唯一字母」的偏序计数，每个数字的个数被线性方程组唯一确定，再按 $0$ 到 $9$ 拼回字符串。






#### Python3


```python
class Solution:
    def originalDigits(self, s: str) -> str:
        counter = Counter(s)
        cnt = [0] * 10

        cnt[0] = counter['z']
        cnt[2] = counter['w']
        cnt[4] = counter['u']
        cnt[6] = counter['x']
        cnt[8] = counter['g']

        cnt[3] = counter['h'] - cnt[8]
        cnt[5] = counter['f'] - cnt[4]
        cnt[7] = counter['s'] - cnt[6]

        cnt[1] = counter['o'] - cnt[0] - cnt[2] - cnt[4]
        cnt[9] = counter['i'] - cnt[5] - cnt[6] - cnt[8]

        return ''.join(cnt[i] * str(i) for i in range(10))
```
