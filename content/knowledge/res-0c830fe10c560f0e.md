## 解法




### 方法一



> **思考**
>
> 从全零数组出发，操作为「某一位加一」或「全体乘二」，要得到 $nums$。 $n\le 10^5$、 $nums[i]\le 10^9$，不能按值模拟。乘二相当于全体同时左移，加一相当于把某数的某个 $1$ 比特写上。
>
> 每个数 $v$ 需要 $v$ 的二进制中 $1$ 的个数次加一；全体共享的乘二次数由最大值的比特长度减一决定。两者相加即为最少调用次数。






#### Python3


```python
class Solution:
    def minOperations(self, nums: List[int]) -> int:
        return sum(v.bit_count() for v in nums) + max(0, max(nums).bit_length() - 1)
```
