## 解法




### 方法一：差分数组



> **思考**
>
> 每个行程在 $[from,to)$ 上增加乘客，判断全程是否都不超过容量。站点坐标 $\le 1000$，适合差分数组而不是按时间排序扫描。
>
> 在起点加人数、终点减人数，再对差分数组求前缀和，检查每个位置是否 $\le \textit{capacity}$。
>
> 数组开到最大终点即可，空位点前缀不变。



我们可以利用差分数组的思想，将每个行程的乘客数加到起点，减去终点，最后我们只需要判断差分数组的前缀和是否都不大于车的最大载客量即可。

时间复杂度 $O(n)$，空间复杂度 $O(M)$。其中 $n$ 是行程数，而 $M$ 是行程中最大的终点，本题中 $M \le 1000$。




#### Python3


```python
class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        mx = max(e[2] for e in trips)
        d = [0] * (mx + 1)
        for x, f, t in trips:
            d[f] += x
            d[t] -= x
        return all(s <= capacity for s in accumulate(d))
```


#### TypeScript


```ts
function carPooling(trips: number[][], capacity: number): boolean {
    const mx = Math.max(...trips.map(([, , t]) => t));
    const d = Array(mx + 1).fill(0);
    for (const [x, f, t] of trips) {
        d[f] += x;
        d[t] -= x;
    }
    let s = 0;
    for (const x of d) {
        s += x;
        if (s > capacity) {
            return false;
        }
    }
    return true;
}
```
