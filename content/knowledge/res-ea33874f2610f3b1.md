## 解法




### 方法一



> **思考**
>
> 手中的球插入棋盘，三颗及以上同色消去，求最少步数清空。插入位置与颜色的组合很多，但棋盘与手球都短。
>
> BFS：状态为当前棋盘与剩余手球。对每种手球、每个插入下标生成新串，用正则反复消去连续三段及以上。空棋盘时步数是已用球数。
>
> 手球按颜色去重再插入，避免同色球重复扩展。访问过的棋盘不再入队。需要继续消去是因为一次消除可能引发连锁。

```python
class Solution:
    def findMinStep(self, board: str, hand: str) -> int:
        def remove(s):
            while len(s):
                next = re.sub(r'B{3,}|G{3,}|R{3,}|W{3,}|Y{3,}', '', s)
                if len(next) == len(s):
                    break
                s = next
            return s

        visited = set()
        q = deque([(board, hand)])
        while q:
            state, balls = q.popleft()
            if not state:
                return len(hand) - len(balls)
            for ball in set(balls):
                b = balls.replace(ball, '', 1)
                for i in range(1, len(state) + 1):
                    s = state[:i] + ball + state[i:]
                    s = remove(s)
                    if s not in visited:
                        visited.add(s)
                        q.append((s, b))
        return -1
```
