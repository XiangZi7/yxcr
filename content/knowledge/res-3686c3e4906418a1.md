## 解法




### 方法一



> **思考**
>
> 奇数位与偶数位可分别任意重排，等价类由这两套字母的可重集合决定。词数 $\le 1000$、长度 $\le 20$，规范化后放入集合即可。
>
> 对每个词把偶位、奇位分别排序再拼接，作为签名。不同签名的个数即组数。






#### Python3


```python
class Solution:
    def numSpecialEquivGroups(self, words: List[str]) -> int:
        s = {''.join(sorted(word[::2]) + sorted(word[1::2])) for word in words}
        return len(s)
```
