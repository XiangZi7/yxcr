## 解法




### 方法一：遍历



> **思考**
>
> 字符串保证合法且长度不超过 $100$，嵌套深度就是扫描过程中未匹配左括号的个数的最大值。
>
> 数字与四则运算符不影响深度，只需处理括号。
>
> 用变量 $d$ 遇 `(` 加一并更新答案，遇 `)` 减一，一遍扫描即可。



我们用一个变量 $d$ 记录当前的深度，初始时 $d = 0$。

遍历字符串 $s$，当遇到左括号时，深度 $d$ 加一，同时更新答案为当前深度 $d$ 和答案的最大值。当遇到右括号时，深度 $d$ 减一。

最后返回答案即可。

时间复杂度 $O(n)$，其中 $n$ 是字符串 $s$ 的长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def maxDepth(self, s: str) -> int:
        ans = d = 0
        for c in s:
            if c == '(':
                d += 1
                ans = max(ans, d)
            elif c == ')':
                d -= 1
        return ans
```


#### TypeScript


```ts
function maxDepth(s: string): number {
    let ans = 0;
    let d = 0;
    for (const c of s) {
        if (c === '(') {
            ans = Math.max(ans, ++d);
        } else if (c === ')') {
            --d;
        }
    }
    return ans;
}
```
