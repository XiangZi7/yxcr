## 解法




### 方法一：模拟



> **思考**
>
> 若先收集所有小于 $x$ 的节点，再收集其余节点并重建链表，结果正确， $n \le 200$ 时间上也没有压力。然而这样要么拷贝节点，要么二次遍历，还容易打乱分区内部的相对次序。
>
> 题目要求的是稳定划分：小于 $x$ 的相对顺序、以及大于等于 $x$ 的相对顺序都不变。因此只需一遍扫描，把节点按取值分流到两条链上，最后把较小一侧的尾接到较大一侧的头。
>
> 指针接到原节点即可，不必另开值拷贝；较大一侧的尾要置空，以免与原后继成环。



我们创建两个链表 $l$ 和 $r$，一个用来存储小于 $x$ 的节点，另一个用来存储大于等于 $x$ 的节点。然后我们将它们拼接起来。

时间复杂度 $O(n)$，其中 $n$ 是原链表的长度。空间复杂度 $O(1)$。




#### Python3


```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def partition(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        l = ListNode()
        r = ListNode()
        tl, tr = l, r
        while head:
            if head.val < x:
                tl.next = head
                tl = tl.next
            else:
                tr.next = head
                tr = tr.next
            head = head.next
        tr.next = None
        tl.next = r.next
        return l.next
```


#### TypeScript


```ts
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function partition(head: ListNode | null, x: number): ListNode | null {
    const [l, r] = [new ListNode(), new ListNode()];
    let [tl, tr] = [l, r];
    for (; head; head = head.next) {
        if (head.val < x) {
            tl.next = head;
            tl = tl.next;
        } else {
            tr.next = head;
            tr = tr.next;
        }
    }
    tr.next = null;
    tl.next = r.next;
    return l.next;
}
```
