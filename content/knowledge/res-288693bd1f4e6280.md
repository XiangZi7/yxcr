## 解法




### 方法一：模拟



> **思考**
>
> 需要把所有子数组和排序后，求第 $\textit{left}$ 到第 $\textit{right}$ 项之和。子数组有 $O(n^2)$ 个， $n\le 10^3$，若再对每个询问区间重新求和会重复劳动，但本题只询问一次。
>
> 枚举左端点并维护向右延伸的前缀和，即可在 $O(n^2)$ 内列出全部子数组和；排序后对指定闭区间求和并对 $10^9+7$ 取模。 $n^2\log n$ 的量级可以接受。



我们可以按照题目的要求，生成数组 $\textit{arr}$，然后对数组进行排序，最后求出 $[\textit{left}-1, \textit{right}-1]$ 范围的所有元素的和，得到结果。

时间复杂度 $O(n^2 \times \log n)$，空间复杂度 $O(n^2)$。其中 $n$ 为题目给定的数组长度。




#### Python3


```python
class Solution:
    def rangeSum(self, nums: List[int], n: int, left: int, right: int) -> int:
        arr = []
        for i in range(n):
            s = 0
            for j in range(i, n):
                s += nums[j]
                arr.append(s)
        arr.sort()
        mod = 10**9 + 7
        return sum(arr[left - 1 : right]) % mod
```


#### TypeScript


```ts
function rangeSum(nums: number[], n: number, left: number, right: number): number {
    let arr = Array((n * (n + 1)) / 2).fill(0);
    const mod = 10 ** 9 + 7;

    for (let i = 0, s = 0, k = 0; i < n; i++, s = 0) {
        for (let j = i; j < n; j++, k++) {
            s += nums[j];
            arr[k] = s;
        }
    }

    arr = arr.sort((a, b) => a - b).slice(left - 1, right);
    return arr.reduce((acc, cur) => (acc + cur) % mod, 0);
}
```
