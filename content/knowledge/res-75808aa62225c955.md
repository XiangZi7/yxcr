## 解法




### 方法一：模拟



> **思考**
>
> 日志表示进入子目录、停留或返回上一级，求回到根所需的最少 $../$ 次数。日志至多 $10^3$ 条，模拟当前深度即可，不必维护真实路径栈。
>
> 遇到非 $\texttt{./}$ 的目录名深度加一； $\texttt{../}$ 则深度与 $0$ 取最大后减一。最终深度就是还需要返回的步数。



直接模拟，记录深度的变化即可。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。其中 $n$ 为 `logs` 的长度。




#### Python3


```python
class Solution:
    def minOperations(self, logs: List[str]) -> int:
        ans = 0
        for v in logs:
            if v == "../":
                ans = max(0, ans - 1)
            elif v[0] != ".":
                ans += 1
        return ans
```


#### TypeScript


```ts
function minOperations(logs: string[]): number {
    let ans = 0;
    for (const x of logs) {
        if (x === '../') {
            ans && ans--;
        } else if (x !== './') {
            ans++;
        }
    }
    return ans;
}
```
