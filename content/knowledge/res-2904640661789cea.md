## 解法




### 方法一：动态规划



> **思考**
>
> 房屋围成环，第一间与最后一间相邻，不能同时偷，线性打家劫舍不能直接套用。
>
> 为此拆成两段：不偷第一间、或不偷最后一间，分别做线性 DP，再取较大者；仅一间时直接返回该值。



环状排列意味着第一个房屋和最后一个房屋中最多只能选择一个偷窃，因此可以把此环状排列房间问题约化为两个单排排列房屋子问题。

时间复杂度 $O(n)$，其中 $n$ 是数组长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        def _rob(nums):
            f = g = 0
            for x in nums:
                f, g = max(f, g), f + x
            return max(f, g)

        if len(nums) == 1:
            return nums[0]
        return max(_rob(nums[1:]), _rob(nums[:-1]))
```


#### TypeScript


```ts
function rob(nums: number[]): number {
    const n = nums.length;
    if (n === 1) {
        return nums[0];
    }
    const robRange = (l: number, r: number): number => {
        let [f, g] = [0, 0];
        for (; l <= r; ++l) {
            [f, g] = [Math.max(f, g), f + nums[l]];
        }
        return Math.max(f, g);
    };
    return Math.max(robRange(0, n - 2), robRange(1, n - 1));
}
```
