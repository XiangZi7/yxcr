## 解法




### 方法一：遍历计数



> **思考**
>
> 统计全为 $1$ 的子串个数， $n\le 10^5$，不能枚举全部 $O(n^2)$ 个子串。被 $0$ 隔开的连续 $1$ 段彼此独立，只需对每段计数。
>
> 长度为 $k$ 的全 $1$ 段贡献 $k(k+1)/2$ 个子串，也等价于扫描时维护当前连续 $1$ 长度 $cur$：每多一个 $1$， $cur$ 加一并把 $cur$ 累入答案；遇到 $0$ 则清零。这样不必预先切段。



我们遍历字符串 $s$，用一个变量 $\textit{cur}$ 记录当前连续的 1 的个数，用变量 $\textit{ans}$ 记录答案。当遍历到字符 $s[i]$ 时，如果 $s[i] = 0$，则 $\textit{cur}$ 置 0，否则 $\textit{cur}$ 自增 1，然后 $\textit{ans}$ 自增 $\textit{cur}$，并对 $10^9 + 7$ 取模。

遍历结束，返回 $\textit{ans}$ 即可。

时间复杂度 $O(n)$，其中 $n$ 为字符串 $s$ 的长度。空间复杂度 $O(1)$。

#### Python3


```python
class Solution:
    def numSub(self, s: str) -> int:
        mod = 10**9 + 7
        ans = cur = 0
        for c in s:
            if c == "0":
                cur = 0
            else:
                cur += 1
                ans = (ans + cur) % mod
        return ans
```


#### TypeScript


```ts
function numSub(s: string): number {
    const mod = 1_000_000_007;
    let [ans, cur] = [0, 0];
    for (const c of s) {
        if (c === '0') {
            cur = 0;
        } else {
            cur++;
            ans = (ans + cur) % mod;
        }
    }
    return ans;
}
```
