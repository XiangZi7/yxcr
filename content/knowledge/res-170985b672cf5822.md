## 解法




### 方法一：贪心 + 模拟



> **思考**
>
> 只有 $5$、 $10$、 $20$，找零必须用手头已有的钞票。 $n\le 10^5$，应贪心：收 $20$ 时优先配一张 $10$ 加一张 $5$，否则三张 $5$。
>
> 维护 $5$ 与 $10$ 的张数，任一步 $5$ 变为负数即失败。无需保存整段交易历史。



我们从前往后遍历账单数组 $bills$，对于当前遍历到的账单：

- 如果是 $5$ 美元，那么直接收下即可；
- 如果是 $10$ 美元，那么需要找零 $5$ 美元；
- 如果是 $20$ 美元，那么需要找零 $15$ 美元，此时有两种找零方式：找零 $1$ 张 $10$ 美元 + $1$ 张 $5$ 美元；找零 $3$ 张 $5$ 美元。我们优先用第一种找零方式，如果没有足够的 $10$ 美元，那么用第二种方式；
- 如果发现 $5$ 美元的数量不够，直接返回 `false`。

遍历结束，说明我们没有遇到无法找零的情况，返回 `true` 即可。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。其中 $n$ 为账单数组 $bills$ 的长度。




#### Python3


```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five = ten = 0
        for v in bills:
            if v == 5:
                five += 1
            elif v == 10:
                ten += 1
                five -= 1
            else:
                if ten:
                    ten -= 1
                    five -= 1
                else:
                    five -= 3
            if five < 0:
                return False
        return True
```


#### TypeScript


```ts
function lemonadeChange(bills: number[]): boolean {
    let [five, ten] = [0, 0];
    for (const x of bills) {
        switch (x) {
            case 5:
                five++;
                break;
            case 10:
                five--;
                ten++;
                break;
            case 20:
                if (ten) {
                    ten--;
                    five--;
                } else {
                    five -= 3;
                }
                break;
        }

        if (five < 0) {
            return false;
        }
    }
    return true;
}
```


### 方法二：一行



> **思考**
>
> 方法一的分支已经覆盖全部找零规则。方法二把同一对计数器压进一次 $\textit{every}$ 遍历，用位运算区分面额。
>
> 语义不变，只是实现压成一行，仍在 $5$ 张数变负时失败。






#### TypeScript


```ts
const lemonadeChange = (bills: number[], f = 0, t = 0): boolean =>
    bills.every(
        x => (
            (!(x ^ 5) && ++f) ||
                (!(x ^ 10) && (--f, ++t)) ||
                (!(x ^ 20) && (t ? (f--, t--) : (f -= 3), 1)),
            f >= 0
        ),
    );
```
