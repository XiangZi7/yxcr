## 解法




### 方法一：DFS



> **思考**
>
> 必须从 $0$ 出发收集全部苹果并返回，每条边走两次（去和回）。 $n\le 10^5$，只能一遍 DFS。
>
> 子树内若既无苹果、子孙也不需继续走，则不必进入。对孩子递归得到的边权（进入该孩子记 $2$）求和，仅当本节点有苹果或子树代价非零时，才把进入边的代价加上返回。根的进入代价为 $0$。






#### Python3


```python
class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        def dfs(u, cost):
            if vis[u]:
                return 0
            vis[u] = True
            nxt_cost = 0
            for v in g[u]:
                nxt_cost += dfs(v, 2)
            if not hasApple[u] and nxt_cost == 0:
                return 0
            return cost + nxt_cost

        g = defaultdict(list)
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        vis = [False] * n
        return dfs(0, 0)
```


### 方法二：显式栈



> **思考**
>
> 必须从 $0$ 出发收集全部苹果并返回，每条用到的边走两次。$n \le 10^5$，从根递归统计每棵子树的往返代价，链上的调用深度就是 $n$，会超出递归栈。
>
> 一棵子树如果自己没有苹果、子孙也不需要再走，就不必进入。孩子都处理完以后，把各孩子的往返代价相加；当前点有苹果或这个和不为 $0$ 时，再加上进入当前点的代价，根是 $0$，其余点是 $2$。
>
> 显式栈按 $(节点, 父节点, 状态)$ 做后序。进入时先压出栈标记再压孩子，离开时按上面的规则写入往返代价。根的代价就是答案。






#### Python3


```python
class Solution:
    def minTime(self, n: int, edges: List[List[int]], hasApple: List[bool]) -> int:
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        cost = [0] * n
        stk = [(0, -1, 0)]
        while stk:
            u, fa, state = stk.pop()
            if state == 0:
                stk.append((u, fa, 1))
                for v in g[u]:
                    if v != fa:
                        stk.append((v, u, 0))
            else:
                nxt = 0
                for v in g[u]:
                    if v != fa:
                        nxt += cost[v]
                if hasApple[u] or nxt:
                    cost[u] = nxt if u == 0 else nxt + 2
        return cost[0]
```


#### TypeScript


```ts
function minTime(n: number, edges: number[][], hasApple: boolean[]): number {
    const g: number[][] = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        g[u].push(v);
        g[v].push(u);
    }
    const cost = Array(n).fill(0);
    const stk: [number, number, number][] = [[0, -1, 0]];
    while (stk.length) {
        const [u, fa, state] = stk.pop()!;
        if (state === 0) {
            stk.push([u, fa, 1]);
            for (const v of g[u]) {
                if (v !== fa) {
                    stk.push([v, u, 0]);
                }
            }
        } else {
            let next = 0;
            for (const v of g[u]) {
                if (v !== fa) {
                    next += cost[v];
                }
            }
            if (hasApple[u] || next > 0) {
                cost[u] = next + (u === 0 ? 0 : 2);
            }
        }
    }
    return cost[0];
}
```
