## 解法




### 方法一：枚举



> **思考**
>
> 枚举所有 $i<j$ 计算 $values[i]+values[j]+i-j$ 为平方级。把式子拆成 $(values[i]+i)+(values[j]-j)$ 后，对固定的 $j$ 只需知道左侧 $values[i]+i$ 的最大值。
>
> 从左到右扫 $j$，用一个变量维护截至 $j-1$ 的 $values[i]+i$，即可在常数时间得到当前位置的最优配对，再把 $values[j]+j$ 纳入维护。
>
> 这样每个景点只作为右端点看一次、作为左端候选更新一次，线性即可。



我们可以从左到右枚举 $j$，同时维护 $j$ 左侧元素中 $values[i] + i$ 的最大值 $mx$，这样对于每个 $j$，最大得分为 $mx + values[j] - j$。我们取所有位置的最大得分的最大值即为答案。

时间复杂度 $O(n)$，其中 $n$ 为数组 $\textit{values}$ 的长度。空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def maxScoreSightseeingPair(self, values: List[int]) -> int:
        ans = mx = 0
        for j, x in enumerate(values):
            ans = max(ans, mx + x - j)
            mx = max(mx, x + j)
        return ans
```


#### TypeScript


```ts
function maxScoreSightseeingPair(values: number[]): number {
    let [ans, mx] = [0, 0];
    for (let j = 0; j < values.length; ++j) {
        ans = Math.max(ans, mx + values[j] - j);
        mx = Math.max(mx, values[j] + j);
    }
    return ans;
}
```
