## 解法




### 方法一：贪心 + 哈希表



> **思考**
>
> 回答 $x$ 表示该颜色共有 $x+1$ 只。不同回答不能同色；相同回答可以分到若干组，每组最多 $x+1$ 只。
>
> 要人数最少，同答 $x$ 的 $v$ 只兔子应尽量填满大小为 $x+1$ 的组，组数为 $\lceil v/(x+1)\rceil$。
>
> 计数后对每种 $x$ 累加组数乘组大小。



根据题目描述，回答相同的兔子，可能属于同一种颜色，而回答不同的兔子，不可能属于同一种颜色。

因此，我们用一个哈希表 $\textit{cnt}$ 记录每种回答出现的次数。对于每种回答 $x$ 及其出现次数 $v$，我们按照每种颜色有 $x + 1$ 只兔子的原则，计算出兔子的最少数量，并将其加入答案。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为数组 $\textit{answers}$ 的长度。




#### Python3


```python
class Solution:
    def numRabbits(self, answers: List[int]) -> int:
        cnt = Counter(answers)
        ans = 0
        for x, v in cnt.items():
            group = x + 1
            ans += (v + group - 1) // group * group
        return ans
```


#### TypeScript


```ts
function numRabbits(answers: number[]): number {
    const cnt = new Map<number, number>();
    for (const x of answers) {
        cnt.set(x, (cnt.get(x) || 0) + 1);
    }
    let ans = 0;
    for (const [x, v] of cnt.entries()) {
        const group = x + 1;
        ans += Math.floor((v + group - 1) / group) * group;
    }
    return ans;
}
```
