## 解法




### 方法一



> **思考**
>
> 连续相同字符要写成字符加次数（次数大于 $1$ 时），且必须原地写回。另开字符串再拷贝违反空间要求。
>
> 读指针 $i$ 找一段相同字符，写指针 $k$ 先写字符，长度大于 $1$ 再写十进制各位。 $i$ 跳到下一段。
>
> 写指针不超越读指针：压缩后长度不超过原长，从左覆盖是安全的。返回 $k$ 作为新长度。






#### Python3


```python
class Solution:
    def compress(self, chars: List[str]) -> int:
        i, k, n = 0, 0, len(chars)
        while i < n:
            j = i + 1
            while j < n and chars[j] == chars[i]:
                j += 1
            chars[k] = chars[i]
            k += 1
            if j - i > 1:
                cnt = str(j - i)
                for c in cnt:
                    chars[k] = c
                    k += 1
            i = j
        return k
```
