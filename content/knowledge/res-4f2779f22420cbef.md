## 解法




### 方法一：枚举组合



> **思考**
>
> 小时取值 $[0,12)$、分钟取值 $[0,60)$，合法时分只有 $720$ 种。题目要求点亮的灯数等于二进制中 $1$ 的个数之和，因此直接枚举每一对 $(i,j)$ 并统计 $1$ 的个数即可。
>
> 规模为常数，不必按灯位做组合再验证时分是否合法；先枚举合法读数、再对照 $\textit{turnedOn}$，实现更短。



题目可以转换为求 $i \in [0, 12)$ 和 $j \in [0, 60)$ 的所有可能组合。

合法组合需要满足的条件是 $i$ 的二进制形式中 1 的个数加上 $j$ 的二进制形式中 1 的个数，结果等于 $\textit{turnedOn}$。

时间复杂度 $O(1)$，空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        return [
            '{:d}:{:02d}'.format(i, j)
            for i in range(12)
            for j in range(60)
            if (bin(i) + bin(j)).count('1') == turnedOn
        ]
```


#### TypeScript


```ts
function readBinaryWatch(turnedOn: number): string[] {
    const ans: string[] = [];

    for (let i = 0; i < 12; ++i) {
        for (let j = 0; j < 60; ++j) {
            if (bitCount(i) + bitCount(j) === turnedOn) {
                ans.push(`${i}:${j.toString().padStart(2, '0')}`);
            }
        }
    }

    return ans;
}

function bitCount(i: number): number {
    i = i - ((i >>> 1) & 0x55555555);
    i = (i & 0x33333333) + ((i >>> 2) & 0x33333333);
    i = (i + (i >>> 4)) & 0x0f0f0f0f;
    i = i + (i >>> 8);
    i = i + (i >>> 16);
    return i & 0x3f;
}
```


### 方法二：二进制枚举



> **思考**
>
> 方法一按合法时分枚举。也可以把 $10$ 盏灯看成 $[0,2^{10})$ 的位掩码：高 $4$ 位为时、低 $6$ 位为分，再过滤 $h<12$、 $m<60$ 且 $\operatorname{popcount}$ 等于 $\textit{turnedOn}$。
>
> 一层循环即与灯位一一对应，语义更贴近「选哪些灯」，渐近复杂度不变。



我们可以利用 $10$ 个二进制位表示手表，其中前 $4$ 位代表小时，后 $6$ 位代表分钟。枚举 $[0, 2^{10})$ 中的每个数，判断其二进制表示中 1 的个数是否等于 $\textit{turnedOn}$，如果是，则将其转换为时间格式加入答案中。

时间复杂度 $O(1)$，空间复杂度 $O(1)$。




#### Python3


```python
class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        ans = []
        for i in range(1 << 10):
            h, m = i >> 6, i & 0b111111
            if h < 12 and m < 60 and i.bit_count() == turnedOn:
                ans.append('{:d}:{:02d}'.format(h, m))
        return ans
```


#### TypeScript


```ts
function readBinaryWatch(turnedOn: number): string[] {
    const ans: string[] = [];

    for (let i = 0; i < 1 << 10; ++i) {
        const h = i >> 6;
        const m = i & 0b111111;

        if (h < 12 && m < 60 && bitCount(i) === turnedOn) {
            ans.push(`${h}:${m < 10 ? '0' : ''}${m}`);
        }
    }

    return ans;
}

function bitCount(i: number): number {
    i = i - ((i >>> 1) & 0x55555555);
    i = (i & 0x33333333) + ((i >>> 2) & 0x33333333);
    i = (i + (i >>> 4)) & 0x0f0f0f0f;
    i = i + (i >>> 8);
    i = i + (i >>> 16);
    return i & 0x3f;
}
```
