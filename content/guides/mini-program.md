# 小程序：页面生命周期与数据更新

小程序页面需要协调视图、逻辑和平台能力。理解页面什么时候创建、什么时候再次显示，以及数据如何传到视图，是排查常见问题的基础。

## 页面生命周期

`onLoad` 适合读取首次进入的路由参数；`onShow` 会在页面显示时执行，适合检查返回页面后的状态；`onReady` 表示首次渲染完成。页面隐藏时处理暂停逻辑，在 `onUnload` 中清理不再使用的计时器与订阅。

不要把必须在每次返回时刷新的数据只放到 `onLoad`。也不要在每次 `onShow` 都无条件启动新的计时器。

```javascript
Page({
  data: { count: 0 },
  onLoad(options) {
    this.itemId = options.id
  },
  increment() {
    this.setData({ count: this.data.count + 1 })
  },
  onUnload() {
    if (this.timer) clearInterval(this.timer)
  }
})
```

## 为什么使用 setData

直接修改逻辑层对象不会自动通知视图更新。`setData` 同步页面数据并安排视图更新，因此要控制传输数据的体积与频率。更新列表中的一个字段时，优先提交具体路径，而不是不断传输整个大数组。

```javascript
this.setData({
  'items[0].selected': true
})
```

## 列表、组件与事件

列表使用稳定的 `wx:key`，避免使用每次渲染都变化的随机值。组件输入使用属性，组件向外通知使用事件；页面作为业务状态的协调者，减少组件之间互相修改内部状态。

表单提交前检查必填字段、阻止重复提交，并在网络请求结束后恢复按钮状态。请求失败时保留用户已经填写的内容。

## 登录状态与权限

登录凭证应由服务端验证，客户端缓存的用户信息不能作为权限依据。每次敏感操作都在服务端校验身份和资源访问范围，并对过期凭证提供可恢复的重新登录流程。
