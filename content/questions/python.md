## 二、实现原理

### 1. 理解核心机制

迭代器实现 __iter__ 和 __next__ 协议，按需返回元素。生成器通过 yield 创建，是实现迭代器的简洁方式，能够暂停与恢复执行，适合处理流式数据。

```python
def numbers(limit):
    for number in range(limit):
        yield number

iterator = numbers(3)
print(next(iterator))  # 0
print(list(iterator))  # [1, 2]
```
