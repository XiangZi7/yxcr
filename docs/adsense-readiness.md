# YXCR OS · Google AdSense 接入准备

本文件用于维护者接入网站展示广告。站点定位为编程与 AI 学习网站，公开维护者为 XiangZi7，联系邮箱为 xiangzi777777@gmail.com。

核对日期：2026-10-27。Google 的要求可能调整，提交与上线前应重新核对下方官方文档。

## 已完成的代码准备

- 独立学习首页：主题入口、学习方法、知识阅读、笔记与自测入口。
- 六个公开信息页面：`/about`、`/contact`、`/privacy`、`/terms`、`/cookies`、`/copyright`。
- 每个页面具有独立标题、摘要、canonical 与分享信息；页面正文由服务端输出，无需登录。
- 全站页脚包含信息页面入口，侧栏包含关于、联系与隐私入口，公开页面加入 sitemap。
- 隐私说明覆盖本地学习数据、同源搜索、访问请求、第三方文章图片、邮件处理、Google 广告 Cookie、个性化退出与同意管理。
- 版权页链接现有 NOTICE、许可文本及逐篇来源记录；学习内容的原始 URL、资源 ID 与许可记录保留。

当前没有发布商 ID、AdSense 广告脚本、Google Analytics、Google Ads 转化追踪或广告同意横幅，也未生成带占位发布商信息的 `ads.txt`。上线准备页面不等于账户验证、广告接入或 Google 审批通过。

## 申请前的实际检查

- [ ] 部署到实际申请域名，确认 HTTPS、手机访问与公开阅读正常，没有认证墙或爬虫阻挡。
- [ ] 确认 `NEXT_PUBLIC_SITE_URL` 为正式域名，并检查页面 canonical、robots.txt 与 sitemap.xml。
- [ ] 实际发送一封测试邮件验证公开邮箱可收信；页面中的邮件按钮会打开邮件客户端，不会直接向本站提交内容。
- [ ] 按实际部署服务核对访问日志、保存期限、处理地点及第三方服务；如与当前说明不同，先更新隐私政策。
- [ ] 抽查主要栏目与落地页的正文、失效图片、代码示例和引用。避免只靠标题、链接列表或空内容页申请。
- [ ] 检查开放许可改编资料的署名与修改说明。拥有再分发许可不等于满足 AdSense 的内容价值要求；需要额外的原创解释、实践、评论或有价值的编排，不能仅镜像或轻度改写原内容。

关于、联系与条款页面有助于解释站点身份和使用方式；隐私披露是 Google 明确提出的要求。Google 不承诺仅因页面齐全、达到固定文章数或固定流量就批准网站。

## 获得真实账户信息后

1. 在 AdSense 中添加正式站点，按账户界面提供的验证方式验证所有权。不要编造 `ca-pub-...` 或复制他人的发布商 ID。
2. 按账户提供的真实记录配置域名根目录 `/ads.txt`。记录中的发布商字段为账户对应的 `pub-...`，以 AdSense 实际给出的完整记录为准；部署后验证返回纯文本内容与正确记录。
3. 决定实际广告位置与适用流量。先只考虑有实质学习内容的阅读页，排除私人笔记、个人记录、练习作答界面以及信息/政策页面，检查自动广告的页面排除配置。
4. 若面向欧洲经济区、英国或瑞士用户提供个性化广告，使用 Google 认证且集成 IAB TCF 的 CMP。可在 AdSense「隐私权和消息」中配置 Google CMP，完成相关地区披露、合作方、拒绝与撤回入口；自制同意按钮不能替代认证要求。
5. 如启用 Google Ads 转化或 Analytics，另行评估并接入相应的同意模式与数据披露；AdSense 站点准备本身不包含这些产品。
6. 上线广告前同步修改 `/privacy`、`/cookies`、`/about`、README 及本文件中「当前未启用」的表述。公开披露实际广告合作方，保持其政策链接与 CMP 配置一致。
7. 在同意、拒绝、撤回和未作选择的情况下检查实际网络请求与存储，确认广告处理符合各适用地区要求。验证隐私选择入口可再次打开，且学习内容仍可访问。
8. 检查广告标识、移动端布局和键盘操作。广告不能覆盖学习内容、伪装成下载/导航按钮、靠近容易误点的操作，或通过提示诱导用户点击。

没有配置真实发布商 ID 和同意管理前，保持当前无广告状态即可，不要把申请验证与正式广告投放混为一谈。
